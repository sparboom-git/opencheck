## What's new in 0.4.3

**Classification codes (WIP)**
- With *WIP* on in *File → Settings*, the card of *Information: LOD DK* has a tick *Classification* with a choice of classification system and edition, so it is never in doubt which list the codes were checked against. OpenCheck ships **BIMTypeCode 2022 DK** (2. udgave, 2023-06-30) by BIM7AA.
- The codes themselves are checked, not only that a code is there: the code is one of the list's codes (571 is a code, 57 is a group and 570 is neither; codes marked *FRI* are not in use), the type id begins with the code, and the code fits the element's IFC class, e.g. no pipe code on a wall. An unknown code names the group it seems to belong to and that group's codes.
- The results have a section of their own, between the fill rates and the missing information: per IFC file the share of codes in order and what is wrong with the rest; under it the elements per discipline, as findings that can be accepted, rejected and turned into issues. The fill rates and the missing information read as before.
- With a system chosen, *Klassifikationskode* and *Type (-kode/-ID)* are read only where that system keeps them, so a CCS or CCI code alone no longer counts as the classification code. *Where to look…* shows those sources and can change them; the code that counts as there is the code that is checked.
- Reports: the check is a card of its own after the fill rates in *Informationsniveau*, with the system, edition and licence, in the PDF, in Word and in the preview.
- Command line: `opencheck classifications` lists the systems, and `opencheck check … --classification bimtypecode-2022-dk` checks against one. Autorun follows the project's choice.
- Which IFC classes a code belongs on is OpenCheck's own judgement and is still being tuned; it is kept wide, so only a clear mismatch is reported.

**Information requirements**
- The standard recognises the property names of BIMTypeCode 2022 (`BIMTypeCode`, `BIMTypeID`) as well as the older BIM7AA names.
- A classification source can be limited to the references of one classification system, in *Where to look…* and in standard files (`scheme`).

**Licences**
- The list of codes of BIMTypeCode 2022 DK is included unchanged under CC BY-ND 4.0. `BIMTypeCode-NOTICE.txt` comes with the download.
