## What's new in 0.3.2

**Claude connection**
- *Triage rules* on the Pre-sort tab: write the project's own rules for sorting findings in plain words, one per line (e.g. "Insulation against pipes in shafts is always C1"). Claude reads them before every review of the project.
- The same window lists the suggestions you approved as another category, which Claude learns from, with Claude's reason. Remove the ones that should not be followed.
- Both are saved in the project, so each project has its own.

Includes everything from 0.3.1: *Issued by* and the filter on issues, issues made by Claude, pictures of findings and coordinates for Claude. After updating, restart Claude Desktop so it picks up the new tools.

## Download
Download `OpenCheck-v0.3.2-windows-x64.zip` below, unzip it and run `opencheck-app.exe`. Windows SmartScreen may warn the first time: click *More info* and then *Run anyway*.
