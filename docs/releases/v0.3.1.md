## What's new in 0.3.1

**Issues**
- Every issue shows who made it under *Issued by*: your initials, or *Claude*. Set your initials under File → Settings → You; by default OpenCheck takes your Windows user name when it is short.
- *Filter* at the top right of the Issues list shows only the issues made by one person, or on one day. Exports without ticked issues take the issues shown.
- Excel templates can show `{{issue.created_by}}`, and BCF files name the issue's maker as its author.

**Claude connection**
- When you allow it (*Let Claude make issues*), Claude can make issues of findings or whole groups when you ask, with a category, title and description. They are marked as issued by Claude.
- Claude can ask for pictures of findings: OpenCheck turns the 3D view to each finding in turn (at an angle, as a plan from the top or as an elevation from one side), with the first element orange and the second blue, and puts your view back afterwards. Claude sees the pictures, and each is saved as a PNG in a folder next to the project file, so a report Claude writes can include them.
- Claude can also ask for a picture of the 3D view as you see it now.
- Findings carry their coordinates: the point in the models' IFC coordinates, in metres.
- After updating, restart Claude Desktop so it picks up the new tools.

**Windows**
- OpenCheck has its own icon, in the window and the taskbar.
- Releases can include an MSIX package for the Microsoft Store (see `docs/microsoft-store.md`).

## Download
Download `OpenCheck-v0.3.1-windows-x64.zip` below, unzip it and run `opencheck-app.exe`. Windows SmartScreen may warn the first time: click *More info* and then *Run anyway*.
