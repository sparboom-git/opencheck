## What's new in 0.4.2

**Microsoft Store**
- OpenCheck is packaged as an MSIX for the Microsoft Store. The package is built with each release and signed by the Store when it is submitted.

**Fixes**
- The build passes clippy on Rust 1.100 (dimension check).

## Download
Download `OpenCheck-v0.4.2-windows-x64.zip` below, unzip it and run `opencheck-app.exe`. Windows SmartScreen may warn the first time: click *More info* and then *Run anyway*.
