## What's new in 0.2.0

**OpenCheck in the browser**
- The app now also runs in the browser: <https://sparboom-git.github.io/opencheck/> (needs WebGPU, e.g. a recent Chrome or Edge). IFC files are opened in the browser and never uploaded.
- Projects open and save in the browser too: *Save* downloads the `.opencheck` file, and opening it (or dropping it on the page) brings the project back. Projects move freely between the browser and the desktop app.
- A loading message shows while a model loads or a check runs, and a welcome note explains the web version.
- Not yet in the browser: updating a model in place, BCF Live and remembering the theme.

**Viewer**
- Walk mode: the person button in the tool bar puts you on a floor; walk at eye height with W A S D, drag to look around, scroll to step, Esc stops.
- Right-click in the model tree to isolate, hide, show, select or zoom to a model, storey, class (e.g. all beams) or element.
- The tool bar wraps onto more rows on narrow screens.
- The working area in *Edit view* is easier to see in the dark theme.

**Checking**
- *Where to look* (information requirements) fits the screen, can be made small, and minimises to a button in the status bar.
- Ruleset Manager: "Within a model" takes one discipline for group A, and group B uses the same model.

## Download
Download `OpenCheck-v0.2.0-windows-x64.zip` below, unzip it and run `opencheck-app.exe`. Windows SmartScreen may warn the first time: click *More info* and then *Run anyway*.
